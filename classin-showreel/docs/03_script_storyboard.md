- 길이 **28.8s** = 100BPM 12마디 (1마디 = 2.4s) → 본편 26.4s + 엔드카드 2.4s
- 포맷 60fps · **16:9(1920×1080)** — v6는 16:9 먼저 (9:16은 확정 후)
- 원 테이크 / 하드컷 0 — 책상 → 뇌 → 고래 → 태블릿 속 수업 → 방 → 새벽 마을은 **하나의 카메라**(`src/js/world.js`)가 이어 찍고, 새벽 이후는 빛이 직접 다음 씬으로 들어간다
- 타이밍의 단일 소스: [`src/timeline.json`](../src/timeline.json) (영상·사운드가 같은 파일을 읽음)
- v4(교실·학생·가족·미래), v5(책→뇌→상상→집, 전체 아이보리)는 git 히스토리에 보존

## 기획 — 「한 아이의 질문」 × 「어둠 → 빛」
> 밤, 서윤의 책상. 연두빛 하나가 공책에 질문을 쓴다 — **"만약에 고래가 하늘을 난다면?"**
> 책을 읽고, 단어가 모여 생각(뇌)이 되고, 상상 속 고래가 그려진다. 그런데 **혼자서는 날아오르지 못하고 흩어진다.**
> 그 질문이 태블릿 속 **ClassIn 수업**에 닿는다. 선생님에게 갔다가(질문), 반 친구들과 함께 그린 답이 되어 서윤에게 돌아온다(답).
> 완성된 고래가 화면을 빠져나와 창밖 새벽 하늘로 — 지나가는 집마다 창문이 켜지고, 해가 떠서 화면이 아이보리로 밝아진다.
> **혼자 품은 질문이, 함께 날아오르도록. ClassIn.**

| 감정선 | 장면 | 톤 |
|---|---|---|
| 궁금함 | 밤의 공책, 빛이 쓰는 질문, 책 | 어둠 + 빛이 닿는 곳만 밝음 (v4의 발광 퀄리티) |
| 몰입 | 단어 → 뇌, 시냅스 발화 | 어둠 속 연두 발광 |
| **막힘** | 고래가 떠오르려다 흩어짐, 음악이 거의 빠짐 | 빛이 꺼져감 |
| 연결 | ClassIn 수업: 질문 → 선생님 → 친구들과 함께 그림 → 답이 돌아옴 | 태블릿의 따뜻한 빛, ClassIn 차콜 UI |
| 날아오름 | 고래가 방을 지나 새벽 마을 위로, 창문들이 켜짐 | 블루아워 → 새벽 → 일출 |
| 브랜드 | 태그라인 + 코드 로고 | **아이보리 + 연두** |

## 원칙
| 기준 | 영상 안에서의 약속 |
|---|---|
| **어둠 → 빛** | 앞 2/3는 어둠 속 발광(빛 한 줄이 실제로 빛남), 수업에서 따뜻해지고, 새벽에 밝아져, 브랜드 순간은 아이보리. 빛 한 줄도 같은 모듈이 밤(가산 발광) ↔ 낮(종이 위 연두)으로 자연스럽게 바뀜 (`fx.light`) |
| **연두는 포인트** | 빛·밑줄·물음표·답이 돌아오는 순간·핵심어 마커·로고에만 |
| **ClassIn의 역할** | 혼자 막힌 질문을 선생님·친구와 잇는 통로 — 실제 기능으로: 라이브 교실, 영상 좌석, 손들기, 채팅, 다중 판서(펜 색·이름표), 판서 권한, 트로피 |
| **코드로 그린 로고** | 공식 글리프 외곽선 → 머티리얼(그레인·베벨·그림자·시인), `i` 점에서 외곽선 트레이스·잉크 번짐 |
