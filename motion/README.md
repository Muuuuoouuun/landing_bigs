# ClassIn Enterprise — 27초 시네마틱 쇼릴 (데모)

미리보기: [`preview/classin-showreel-preview.mp4`](preview/classin-showreel-preview.mp4) · 스토리보드: [`preview/classin-showreel-storyboard.jpg`](preview/classin-showreel-storyboard.jpg)

대형 교육기관(다지점 학원 본사)을 타깃으로 한 27초 키네틱 타이포그래피 모션 그래픽입니다.
[Remotion](https://www.remotion.dev) (React 기반 영상 렌더링)으로 제작되어, 코드 수정 → 즉시 미리보기 → MP4 렌더가 가능합니다.

- 해상도 / 프레임: 1920×1080 · 30fps · 810프레임 (정확히 27.0초)
- 톤: 밝은 라이트 테마. 쿨 오프화이트 배경과 딥 네이비 타이포에 파스텔 포인트(민트·스카이·라벤더·버터·피치)를 얹었고, 그림자는 네이비 틴트로 부드럽게만 씁니다. 대형 기관 의사결정자에게 신뢰감 있게 읽히도록 네온·다크 대신 이 톤을 택했습니다(아래 '컬러 시스템' 참고).
- 폰트: Pretendard(본문/헤드라인), JetBrains Mono(HUD·숫자), 나눔손글씨 펜(Nanum Pen Script, 화이트보드 판서) — 모두 npm에서 로컬 로드, 렌더 시 네트워크 불필요
- 사운드: 컷에 맞춘 시네마틱 BGM(D단조 → D장조, 128.6 BPM, 1박 = 14프레임)과 효과음 54종. 훅의 네 음 모티프가 챕터마다 다른 악기로 돌아오고, 스트링·합창·호른·팀파니로 무게를 실었습니다. 효과음은 모두 BGM의 16분음표 그리드에 맞춰 떨어지고, 음높이가 있는 소리는 그 순간 울리는 코드에서 음을 골라 음악과 한 곡처럼 들립니다. 전환마다 다른 소리를 쓰고, 비프음·글리치·틱 같은 날카로운 소리는 뺐습니다. 전부 코드로 합성한 오리지널이라 저작권 걱정이 없고, -14 LUFS / -1 dBTP로 마스터링했습니다.

## 이야기 구조

AI가 "가능한 이유"를 인과로 보여줍니다.

**문제 → 하나의 기준 → ① 표준화**(같은 인프라·수업·콘텐츠) **→ ② 관리**(보안·녹화·권한·데이터 축적) **→ 변주 인터루드**(모든 수업이, 본사의 자산으로) **→ 쌓인 데이터 위에서 ③ AI → ④ 가치**(비용↓ 품질↑) **→ 로고**

기능 파트(① 표준화 · ② 관리 · ③ AI 강의평가)는 제품 필름처럼 **와이드 ↔ 클로즈업 컷 편집**으로 보여줍니다. 전체 구도를 보여 준 뒤 기능 하나하나를 박자에 맞춰 크게 끊어 보여 주고, 클로즈업마다 한 줄 설명을 붙였습니다(`src/components/Camera.jsx`의 샷 리스트).

정중앙(14.1–15.9초)의 **인터루드**는 같은 주제를 다른 질감으로 다시 들려주는 '변주'입니다. 본편은 쿨 화이트 위에 카드가 떠 있고 이징이 부드럽습니다. 인터루드는 그 대신 웜 아이보리 종이, 스위스 그리드, 플랫 파스텔 블록, 2프레임 스텝 모션(스톱모션 스타카토)을 쓰고, 음악도 신스 그루브에서 마림바 모티프로 바뀝니다.

## 실행

```bash
cd motion
npm install
npm run studio          # 브라우저 스튜디오에서 타임라인 미리보기/스크럽
npm run render          # 마스터 MP4 (CRF 17) → out/classin-showreel.mp4
npm run render:preview  # 공유용 경량 MP4 (CRF 27) → out/classin-showreel-preview.mp4
```

> Chrome Headless Shell은 첫 렌더 시 Remotion이 자동으로 내려받습니다.
> 이미 설치된 브라우저를 쓰려면 `--browser-executable=<path>`를 붙이세요.

특정 프레임만 확인: `./render-stills.sh ClassInShowreel 120 380 560` → `out/stills/`

## 사운드 (BGM + 효과음)

모든 사운드는 `audio/` 아래 파이썬 코드가 numpy/scipy로 합성합니다 (샘플·외부 음원 없음). 진입점은 `audio/generate.py`이고, 음악은 `score.py`, 효과음은 `sfx.py`, 합성 악기는 `instruments.py`, 필터·리버브·컴프레서 같은 공용 처리는 `dsp.py`, 박자 그리드와 코드 진행(어느 프레임에 어떤 코드가 울리는지)은 `grid.py`에 있습니다.

```bash
pip install -r audio/requirements.txt   # numpy, scipy
npm run audio                           # public/audio/ 아래 WAV 재생성
```

- `src/audio/soundtrack.json` — 오디오 싱크의 단일 기준. 음악 섹션(스타일·코드 진행·구간), 멜로디(모티프가 돌아오는 자리), 팀파니 히트·숨 멈춤(`gaps`)·심벌 스웰, 브레이크, 필인, 크래시, 덕킹, 그리고 효과음 큐(`at`, `sfx`, `volume`)가 모두 여기 있습니다. 큐의 `at`은 소리가 **때려야 하는 프레임**(휙 소리의 정점, 컷의 틱, 벨의 어택, 스웰의 끝)이고, 생성기가 그 지점을 가장 가까운 16분음표(3.5프레임 간격)에 샘플 단위로 맞춥니다. 소리가 화면보다 최대 100 ms 늦을 수는 있어도 43 ms 넘게 앞서지는 않게 하고, 같은 악기가 연달아 같은 칸에 떨어지면 다음 16분음표로 밀어 리듬을 지킵니다. 정확히 그 프레임이어야 하면 `"snap": false`를 붙이세요.
- `public/audio/soundtrack.wav` — 음악 + 효과음 프리믹스를 리미터로 마스터링한 최종본. 렌더 기본값.
- `public/audio/music.wav`, `public/audio/sfx/*.wav` — 스템. 음높이가 있는 효과음은 그 자리 코드에 맞춰 코드별로 따로 만들어집니다(`tap-2-bb.wav`처럼 이름 끝이 코드).
- `src/audio/cues.generated.json` — `npm run audio`가 쓰는 파일(직접 고치지 않음). 박자에 맞춘 뒤 각 큐 파일이 시작하는 프레임과 파일 이름이 들어 있어, 스튜디오의 Props 패널에서 `audio: "stems"`로 바꾸면 이 배치대로 큐를 개별 트랙으로 재생합니다. JSON을 고친 뒤 `npm run audio`를 다시 실행하세요. (`"off"`는 무음)

| 구간 | 음악 | 주요 효과음 |
|---|---|---|
| 0–1.9s | 어두운 스트링 드론 위로 **테마 모티프**(펠트 피아노 D–A–F–E) · 심장박동 킥 · 8분→16분으로 조여드는 첼로 · 임팩트 직전 4프레임 숨 멈춤 | 오프닝 '웅'(D–A 벨) · Dm 리버스 스웰 |

이번 버전에서 달라진 점:

- **박자와 코드에 맞춘 효과음** — 모든 큐가 자기 정점·어택을 16분음표 그리드에 샘플 단위로 맞춥니다(이전에는 76개 중 30개가 20 ms 넘게, 최대 54 ms 어긋나 있었음). 휙 소리는 8분음표, 줌은 한 박, 컷의 포커스 풀은 16분음표만큼 정확히 차오르고, 아르페지오는 16분·32분음표로, 벨류는 점8분 에코로 반복이 박에 떨어집니다. 음높이가 있는 효과음(탭·벨·체크 사다리·블록·녹화·차단·로고 블룸·붐과 쿵)은 그 순간 울리는 코드에서 음을 골라, B♭ 위의 A나 C 코드 위의 F처럼 반음으로 부딪히던 음이 사라졌습니다. 인터루드의 마림바도 정확한 16분음표로 고르게 맞췄습니다.
- **모티프 관통** — 훅의 네 음(D–A–F–E)이 드롭의 바이올린, AI의 글래스 플럭, 로고의 벨(장조로 풀린 D–A–F♯–D)로 돌아옵니다.
- **오케스트라 레이어** — 스트링 섹션(활 노이즈·바디 공명), 포먼트 합창, 소프트 호른, 팀파니를 새로 합성했습니다. 세 번의 큰 타격(임팩트·AI 슬램·로고) 직전에는 음악이 3~4프레임 숨을 멈춥니다.
- **조성에 맞춘 효과음** — 붐마다 그 순간의 코드로 오케스트라 히트를 얹고(Dm·F·D 장조), 리버스 스웰은 그 아래 화성(Dm, 도미넌트 A)으로 숨을 들이쉽니다. 전환마다 고유한 소리(줌·푸시·아이리스·와이프·윕·딥)를 붙였고, 반복되는 소리는 변형(포커스 풀 5종, 취소선 4종, 판서 3종)을 둡니다.
- **거슬리던 소리 정리** — 휙 소리·스웰·호른의 가변 필터가 블록마다 상태를 리셋해 187 Hz 버즈와 고역 잡음을 만들던 문제를 고쳤습니다. 잔향 꼬리가 잘리며 큐 끝마다 나던 클릭도 없애 모든 효과음이 무음으로 끝나고, 영상 끝도 페이드로 닫습니다.
- **믹스** — 공용 홀 리버브(초기 반사 + 어두워지는 꼬리, 120 Hz 이하는 보내지 않음), 킥 사이드체인, 드럼 병렬 압축, 효과음이 나올 때 음악이 살짝 비켜나는 덕킹. 마스터는 −13.7 LUFS / −1.1 dBTP이고, 히트 순간 리미터 개입은 약 0.5 dB라 타격이 눌리지 않습니다. 이전 버전보다 5 kHz 이상은 약 2 dB 낮고 1–2.5 kHz는 약 2.7 dB 높아, 쏘지 않으면서 소리가 앞으로 나옵니다.
