# ClassIn Enterprise — 23초 시네마틱 쇼릴 (데모)

미리보기: [`preview/classin-showreel-preview.mp4`](preview/classin-showreel-preview.mp4) · 스토리보드: [`preview/classin-showreel-storyboard.jpg`](preview/classin-showreel-storyboard.jpg)

대형 교육기관(다지점 학원 본사)을 타깃으로 한 23초 키네틱 타이포그래피 모션 그래픽입니다.
[Remotion](https://www.remotion.dev) (React 기반 영상 렌더링)으로 제작되어, 코드 수정 → 즉시 미리보기 → MP4 렌더가 가능합니다.

- 해상도 / 프레임: 1920×1080 · 30fps · 700프레임 (정확히 23.33초)
- 톤: 딥 포레스트 블랙 + ClassIn 그린(#00df45) + 골드 포인트 — 랜딩 페이지와 동일한 브랜드 팔레트
- 폰트: Pretendard(본문/헤드라인), JetBrains Mono(HUD·숫자) — 모두 npm에서 로컬 로드, 렌더 시 네트워크 불필요
- 사운드: 컷에 맞춘 BGM(128.6 BPM, 1박 = 14프레임) + 효과음 43종 — 전부 코드로 합성한 오리지널 사운드라 저작권 걱정 없음, -14 LUFS / -1 dBFS 마스터링

## 이야기 구조

AI가 "가능한 이유"를 인과로 보여줍니다.

**문제 → 하나의 기준 → ① 표준화**(같은 인프라·수업·콘텐츠) **→ ② 관리**(보안·녹화·권한·데이터 축적) **→ 변주 인터루드**(모든 수업이, 본사의 자산으로) **→ 쌓인 데이터 위에서 ③ AI → ④ 가치**(비용↓ 품질↑) **→ 로고**

정중앙(11.7–13.6초)의 **인터루드**는 같은 주제를 반대 질감으로 다시 들려주는 '변주'입니다: 다크 글래스·발광 HUD·부드러운 이징 대신 아이보리 종이·스위스 그리드·플랫 컬러 블록·2프레임 스텝 모션(스톱모션 스타카토), 음악도 신스 그루브 대신 마림바 모티프로 바뀝니다.

## 실행

```bash
cd motion
npm install
npm run studio          # 브라우저 스튜디오에서 타임라인 미리보기/스크럽
npm run render          # 마스터 MP4 (CRF 17) → out/classin-showreel.mp4
npm run render:preview  # 공유용 경량 MP4 (CRF 27) → out/classin-showreel-preview.mp4
```

> Chrome Headless Shell은 첫 렌더 시 Remotion이 자동으로 내려받습니다.
> 이미 설치된 브라우저를 쓰려면 `--browser-executable=<path>`를 붙이세요.

특정 프레임만 확인: `./render-stills.sh ClassInShowreel 120 380 560` → `out/stills/`

## 사운드 (BGM + 효과음)

모든 사운드는 `audio/generate.py`가 numpy/scipy로 합성합니다 (샘플·외부 음원 없음).

```bash
pip install -r audio/requirements.txt   # numpy, scipy
npm run audio                           # public/audio/ 아래 WAV 재생성
```

- `src/audio/soundtrack.json` — 오디오 싱크의 단일 기준. 음악 섹션(스타일·코드 진행·구간), 브레이크, 필인, 크래시, 덕킹, 그리고 효과음 큐(`at` 프레임, `sfx`, `volume`)가 모두 여기 있습니다.
- `public/audio/soundtrack.wav` — 음악 + 효과음 프리믹스를 리미터로 마스터링한 최종본. 렌더 기본값.
- `public/audio/music.wav`, `public/audio/sfx/*.wav` — 스템. 스튜디오의 Props 패널에서 `audio: "stems"`로 바꾸면 큐를 개별 트랙으로 재생하므로, JSON만 고쳐서 바로 들어볼 수 있습니다. 확정 후 `npm run audio`로 마스터를 다시 만드세요. (`"off"`는 무음)

| 구간 | 음악 | 주요 효과음 |
|---|---|---|
| 0–1.9s | 저음 드론 · 심장박동 킥 · 가속하는 시계 틱 | 스캔 스윕, 노드 블립, 카운터 롤, 리버스 심벌, 글리치 |
| 1.9–8.0s | **드롭** (drive) — 4/4 킥 · 클랩 · 하이햇 · 펌핑 베이스 · 톱니파 아르페지오, Dm–B♭–C–A | 임팩트 + 서브 드롭 · 슬램 · 부팅음(인프라) · 펜 판서음 · 데이터 칩 · 카드 플립 |
| 8.0–11.7s | **관리** (secure) — 하프타임 드럼 · 16분 펄스 베이스 · 어두운 패드 · 데이터 블립 텍스처, 칸마다 코드 전환 Dm–B♭–Gm–C | 자물쇠 '철컥' · 차단 버저 · REC 비프 · 저장 차임 · 토글 클릭 · 블록 적재음 |
| 11.7–13.6s | **변주** (variation) — F 장조 마림바: 컬러 블록이 찍힐 때마다 한 음씩 올라가는 모티프, 문장 단어마다 코드 스탭(F–B♭–C), 마지막 박 픽업 · 드라이한 가벼운 퍼커션 · 펌핑 없음 | 셔터 '찰칵'(종이 컷) · 크래시 · 종이 접힘 · 골드 도장 '쿵' |
| 13.6–14.5s | 브레이크 — "쌓인 데이터 위에서," 정적, A 코드 | 28프레임 라이저 + 데이터 스트림 |
| 14.5–17.8s | **AI 드롭** (ai) — 스퀘어 아르페지오 · 옥타브 베이스 | 대형 임팩트 + 글리치 + 서브 드롭 · 분석 험 · 휠 틱 · 점수 카운터 · 타이핑 · A+ 딩 · 완료 차임 |
| 17.8–21.1s | **장조 리프트** (lift) — F–B♭–C, 밝은 아르페지오 · 오픈 하이햇 | 슬램 · 취소선 '스윽' 4번 · 교차점 히트 · 상승 체크 차임 사다리 4단 |
| 21.1–23.3s | 드럼 아웃 → A 텐션 → **D 메이저 피날레 코드** · 페이드아웃 | 롱 라이저 · 로고 임팩트 + 시머 |

## 구조

```
src/
  Showreel.jsx            마스터 타임라인 (TransitionSeries + 글로벌 오버레이)
  theme.js / fonts.js     팔레트·이징·폰트
  components/
    Kinetic.jsx           KineticText(rise/slam/blur/flip/scramble/pop/drop), RollingNumber, WordSlot, Typewriter
    Fx.jsx                Grain, Vignette, Letterbox, Flash, Shake, Shockwave, LensStreak, SliceGlitch
    Background.jsx        GridFloor, GridPlane, Dust, SpeedLines
    ClassroomWindow.jsx   ClassIn 수업 화면 목업 (판서 그래프 · 풀이 · 학생 상호작용, `t` 하나로 전체 동기화)
    ChapterPill.jsx       챕터 표시 (01 표준화 · 02 관리 · 03 AI · 04 가치)
  scenes/
    BranchesScene.jsx     01 훅 + 하나의 기준
    StandardizeScene.jsx  ① 같은 인프라 · 수업 · 콘텐츠
    ManageScene.jsx       ② 관리 2×2 관제판
    VariationScene.jsx    변주 인터루드 (아이보리 종이 · 스위스 그리드 · 2프레임 스텝 모션)
    AIIntroScene.jsx      브릿지(데이터 코어) + AI 슬램
    AIEvalScene.jsx       AI 강의평가
    ValueScene.jsx        ④ 비용↓ 품질↑ 교차 그래프
    OutroScene.jsx        로고 엔드카드
  audio/
    soundtrack.json       음악 섹션 + 효과음 큐 시트 (오디오 싱크 기준)
    Soundtrack.jsx        mix / stems / off 재생
  transitions/            zoomBlur, lightWipe, whipUp, dip, iris (커스텀 전환)
```

카피·숫자·타이밍은 각 씬 파일 상단 상수(`*_DURATION`, `IMPACT`, `SLAM`, `BEATS`, `STEP`, `COPY`, `PILLARS` 등)에서 바로 수정할 수 있습니다. 씬 길이를 바꾸면 컷이 음악 박(14프레임)에서 벗어나니, `src/audio/soundtrack.json`의 프레임도 함께 맞추고 `npm run audio`를 다시 실행하세요.

## 확인이 필요한 부분

- **수치**: "신규 지점 1일 오픈", "데이터 손실 0건", 지점 수 128은 현재 랜딩 페이지 카피를 그대로 가져온 데모 값입니다. 외부 공개 전 실제 수치로 검증이 필요합니다. 비용 절감 폭은 수치 없이 정성적으로 표현했습니다.
- **연출용 샘플 데이터**: AI 강의평가 점수·발화 비율·AI 요약, 관리 관제판의 암호문·접근 로그·권한 매트릭스·누적 기록 수(24,816건), 가치 그래프의 곡선 모양은 모두 연출용입니다.
- **사운드**: 합성 오리지널이라 라이선스 문제는 없지만, 최종 광고용이라면 전문 사운드 디자이너의 음원이나 라이선스 음원으로 교체하는 것도 고려해 보세요. 교체 시 `soundtrack.json`의 프레임 기준을 그대로 쓰면 싱크가 맞습니다.
- **Remotion 라이선스**: 개인 및 직원 3명 이하 회사는 무료이고, 그 이상 규모의 회사가 사용할 때는 [Company License](https://www.remotion.pro)가 필요합니다.
