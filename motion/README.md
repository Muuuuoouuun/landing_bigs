# ClassIn Enterprise — 27초 시네마틱 쇼릴 (데모)

미리보기: [`preview/classin-showreel-preview.mp4`](preview/classin-showreel-preview.mp4) · 스토리보드: [`preview/classin-showreel-storyboard.jpg`](preview/classin-showreel-storyboard.jpg)

대형 교육기관(다지점 학원 본사)을 타깃으로 한 27초 키네틱 타이포그래피 모션 그래픽입니다.
[Remotion](https://www.remotion.dev) (React 기반 영상 렌더링)으로 제작되어, 코드 수정 → 즉시 미리보기 → MP4 렌더가 가능합니다.

- 해상도 / 프레임: 1920×1080 · 30fps · 810프레임 (정확히 27.0초)
- 톤: 밝은 라이트 테마. 쿨 오프화이트 배경과 딥 네이비 타이포에 파스텔 포인트(민트·스카이·라벤더·버터·피치)를 얹었고, 그림자는 네이비 틴트로 부드럽게만 씁니다. 대형 기관 의사결정자에게 신뢰감 있게 읽히도록 네온·다크 대신 이 톤을 택했습니다(아래 '컬러 시스템' 참고).
- 폰트: Pretendard(본문/헤드라인), JetBrains Mono(HUD·숫자) — 모두 npm에서 로컬 로드, 렌더 시 네트워크 불필요
- 사운드: 컷에 맞춘 BGM(128.6 BPM, 1박 = 14프레임)과 효과음 32종. 무겁고 따뜻한 톤으로 설계했습니다. 딥 킥, 웜 스네어, 서브 베이스, 펠트 피아노, 스트링 패드를 쓰고, 비프음·글리치·틱 같은 날카로운 소리는 뺐습니다. 전부 코드로 합성한 오리지널이라 저작권 걱정이 없고, -14 LUFS / -1 dBFS로 마스터링했습니다.

## 이야기 구조

AI가 "가능한 이유"를 인과로 보여줍니다.

**문제 → 하나의 기준 → ① 표준화**(같은 인프라·수업·콘텐츠) **→ ② 관리**(보안·녹화·권한·데이터 축적) **→ 변주 인터루드**(모든 수업이, 본사의 자산으로) **→ 쌓인 데이터 위에서 ③ AI → ④ 가치**(비용↓ 품질↑) **→ 로고**

기능 파트(① 표준화 · ② 관리 · ③ AI 강의평가)는 제품 필름처럼 **와이드 ↔ 클로즈업 컷 편집**으로 보여줍니다. 전체 구도를 보여 준 뒤 기능 하나하나를 박자에 맞춰 크게 끊어 보여 주고, 클로즈업마다 한 줄 설명을 붙였습니다(`src/components/Camera.jsx`의 샷 리스트).

정중앙(14.1–15.9초)의 **인터루드**는 같은 주제를 다른 질감으로 다시 들려주는 '변주'입니다. 본편은 쿨 화이트 위에 카드가 떠 있고 이징이 부드럽습니다. 인터루드는 그 대신 웜 아이보리 종이, 스위스 그리드, 플랫 파스텔 블록, 2프레임 스텝 모션(스톱모션 스타카토)을 쓰고, 음악도 신스 그루브에서 마림바 모티프로 바뀝니다.

## 실행

```bash
cd motion
npm install
npm run studio          # 브라우저 스튜디오에서 타임라인 미리보기/스크럽
npm run render          # 마스터 MP4 (CRF 17) → out/classin-showreel.mp4
npm run render:preview  # 공유용 경량 MP4 (CRF 27) → out/classin-showreel-preview.mp4
```

> Chrome Headless Shell은 첫 렌더 시 Remotion이 자동으로 내려받습니다.
> 이미 설치된 브라우저를 쓰려면 `--browser-executable=<path>`를 붙이세요.

특정 프레임만 확인: `./render-stills.sh ClassInShowreel 120 380 560` → `out/stills/`

## 사운드 (BGM + 효과음)

모든 사운드는 `audio/generate.py`가 numpy/scipy로 합성합니다 (샘플·외부 음원 없음).

```bash
pip install -r audio/requirements.txt   # numpy, scipy
npm run audio                           # public/audio/ 아래 WAV 재생성
```

- `src/audio/soundtrack.json` — 오디오 싱크의 단일 기준. 음악 섹션(스타일·코드 진행·구간), 브레이크, 필인, 크래시, 덕킹, 그리고 효과음 큐(`at` 프레임, `sfx`, `volume`)가 모두 여기 있습니다.
- `public/audio/soundtrack.wav` — 음악 + 효과음 프리믹스를 리미터로 마스터링한 최종본. 렌더 기본값.
- `public/audio/music.wav`, `public/audio/sfx/*.wav` — 스템. 스튜디오의 Props 패널에서 `audio: "stems"`로 바꾸면 큐를 개별 트랙으로 재생하므로, JSON만 고쳐서 바로 들어볼 수 있습니다. 확정 후 `npm run audio`로 마스터를 다시 만드세요. (`"off"`는 무음)

| 구간 | 음악 | 주요 효과음 |
|---|---|---|
| 0–1.9s | 어두운 스트링 드론 · 떨어지는 펠트 피아노 모티프 · 심장박동 킥 · 8분→16분으로 조여드는 첼로 오스티나토 | 오프닝 '웅' · 리버스 스웰 |
| 1.9–8.9s | **드롭** (drive) — 딥 킥 4/4 · 웜 스네어 · 셰이커 · 서브 베이스 8분 · 펠트 피아노 아르페지오 · 스트링 패드, Dm–B♭–F–C | 시네마틱 붐 · 묵직한 슬램 · 부드러운 휙 소리(컷) · 전원 켜짐 · 마커 판서 · 말렛 탭 · 따뜻한 벨 |
| 8.9–14.1s | **관리** (secure) — 투비트 그루브 · 홀드 베이스 · 낮은 피아노 펄스 · 어두운 패드, 샷마다 코드 전환 Dm–B♭–Gm–Dm–B♭–C | 자물쇠 '덜컥' · 차단(낮은 두 음) · REC(올라가는 두 음) · 저장 벨 · 권한 탭 · 블록 적재 · 4칸 점등 벨 |
| 14.1–15.9s | **변주** (variation) — F 장조 소프트 마림바: 블록이 찍힐 때마다 한 음씩 올라가는 모티프, 단어마다 코드 스탭, 마지막 박 픽업 · 가벼운 퍼커션 | 종이 컷 · 종이 접힘 · 도장 '쿵' |
| 15.9–16.9s | 브레이크 — "쌓인 데이터 위에서," A 코드 + 점점 빨라지는 피아노 | 28프레임 리버스 스웰 |
| 16.9–21.1s | **AI 드롭** (ai) — 클랩 레이어 · 옥타브 베이스 · 16분 피아노 · 코드마다 벨 | 대형 붐 · 레이더 상승 음 · A+ 벨 · 완료 벨 |
| 21.1–24.3s | **장조 리프트** (lift) — F–B♭–C, 높은 피아노 · 밝은 패드 | 슬램 · 부드러운 취소선 4번 · 교차점 붐 + 벨 · 상승 체크 사다리 4단 |
| 24.3–27.0s | A 텐션 + 상승 피아노 → **D 메이저 피날레 코드**(스트링 + 피아노 롤) · 페이드아웃 | 롱 스웰 · 로고 붐 + 벨 블룸 |

이번 버전에서 뺀 소리는 비프·블립, 데이터 칩 소리, 카운터 틱, 타이핑, 글리치, 차단 버저, 하이햇입니다. 2.5–9 kHz 대역은 이전 버전보다 평균 약 6 dB 낮췄습니다.

```
    AIIntroScene.jsx      브릿지(데이터 코어) + AI 슬램
    AIEvalScene.jsx       AI 강의평가
    ValueScene.jsx        ④ 비용↓ 품질↑ 교차 그래프
    OutroScene.jsx        로고 엔드카드
  audio/
    soundtrack.json       음악 섹션 + 효과음 큐 시트 (오디오 싱크 기준)
    Soundtrack.jsx        mix / stems / off 재생
  transitions/            zoomBlur, lightWipe, whipUp, dip, iris (커스텀 전환)
```

카피·숫자·타이밍은 각 씬 파일 상단 상수(`*_DURATION`, `IMPACT`, `SLAM`, `BEATS`, `STEP`, `SHOTS`, `COPY`, `PILLARS` 등)에서 바로 수정할 수 있습니다. 씬 길이를 바꾸면 컷이 음악 박(14프레임)에서 벗어나니, `src/audio/soundtrack.json`의 프레임도 함께 맞추고 `npm run audio`를 다시 실행하세요.
