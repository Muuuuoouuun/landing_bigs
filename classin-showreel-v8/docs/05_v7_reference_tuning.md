### 원본이 고급스러운 진짜 이유 (v6와의 차이)

| 21초, 장면당 1~2초로 빠름 | 28.8초, 뇌 장면 5초 | 중간이 늘어짐 |

## 2. 적용점 — 원본 문법 → ClassIn

| 원본 | ClassIn v7 |
|---|---|
| 빛 슬램 → 로고 리빌 | 연두빛이 `i` 점 자리에 **슬램** → 코드 로고가 어둠 속에서 C→n 리빌 |
| 로고에서 빛이 떨어져 **폰 테두리**가 됨 | 로고의 **`i` 점이 떨어져 공책 위 펜 끝**이 됨 (로고 → 아이의 질문) |
| 검색창 타이핑 | 공책에 손글씨 질문 **"만약에 고래가 하늘을 난다면?"** (물음표가 연두로 빛남) |
| 카드 6장이 3D 부채꼴로 | 책이 3D로 넘어가고, **읽은 단어들이 날아올라 고래 모양**으로 모임 |
| (원본엔 없음 — 우리의 감정 장치) | **막힘**: 고래가 뜨려다 흩어짐, 음악이 속삭임으로 |
| Buy Now → 주문 완료 | 태블릿의 **ClassIn 수업**: 손들기 → 질문이 선생님께 → 함께 판서 → **답이 돌아옴 + 트로피** |
| 카메라가 화면 관통 | 고래가 **태블릿 화면을 뚫고** 방으로 → 창밖 |
| 밤의 도시 + `Arriving today` 트래커 | **새벽 마을** 위를 나는 고래, 창문마다 불 + 글래스 카드 **`오늘의 수업` 트래커: 질문 → 함께 그리기 → 답 → 리포트** |
| 현관 박스 + 스마일 낙인 | 아침 햇살의 책상: 공책 질문 아래 **서윤이 그린 답(날개 단 고래)**, 빛이 내려와 **`i` 점 도장**으로 착지 → 잉크로 식음 |
| `Delivered` 알림 | **`ClassIn 학부모 · 오늘의 수업 리포트가 도착했어요`** — "서윤이가 질문하고 트로피를 받았어요 🏆" |
| `Everything you love.` / `From A to Z.` | **`혼자 품은 질문이,`** / **`함께 날아오르도록.`** — 강조어 한 줄에 하나(질문 / 함께) |
| 화살표가 A→Z를 잇고 스마일이 됨 | `함께` 아래 밑줄 빛이 **질문의 물음표 점 → 로고의 `i` 점**으로 휘어 들어감 (질문 → ClassIn) |
| 숨 → 로고 히트 | 숨 → **`i` 점 착지**, 로고 외곽선 트레이스 + 잉크 (코드 로고) |
| 점 → 선 → 엔드카드 | 동일. "한 아이의 질문에서, 모든 집의 상상까지." + 1,000+ 다지점 학원 |

## 3. 제작 레이어 원칙 (v7)

| 레이어 | 무엇 | 방법 |

| **오브젝트 (움직임·빛 반응)** | 공책, 책(페이지 넘김), 태블릿, 책상 상판 | three.js 3D + 생성 질감(종이·표지·나무) |

| **톤** | 어둠 → 수업의 따뜻한 빛 → 새벽 → 아이보리 + 연두 | v6 그대로 |

### 서사 구조 — 하나에서 전국으로
> **한 아이**(공책의 질문) → **한 교실**(ClassIn 수업에서 함께) → **집집마다**(반 친구들의 창문 → 이웃집) → **전국**(1,000+ 다지점 학원) → 다시 **한 아이**(아침 공책의 `i` 점 도장, 학부모 알림) → **ClassIn**

### v6 대비 변경 요약
- **훅 추가**: 0.2초 슬램 + 로고 리빌 → 로고의 `i` 점이 펜 끝이 됨 (원본의 "로고 → 제품" 핸드오버)
- **뇌 장면 삭제**: 단어가 바로 고래로 모임 (5초 → 2.4초)
- **"집집마다 → 전국" 복원**: 마을의 창문 → 한반도 도트맵 위로 번지는 빛 (v4 지도 + v5 집집마다)
- **증명 문구**: 트래커 `오늘의 수업`, `전국 1,000+ 다지점 학원`, 알림 `수업 리포트가 도착했어요`, 트로피 `+1`
- **물리적 착지**: 아침 공책 위 `i` 점 도장 (원본의 박스 위 스마일)
- **의미 회수**: 밑줄 빛 → 물음표의 점 → 로고의 `i` 점
- **길이**: 28.8s 유지 (기존 음악 구조와 동일: 드롭 4.8 · 리프트 12.0 · 숨 23.4 · 히트 24.0)
